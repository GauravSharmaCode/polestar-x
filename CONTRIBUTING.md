# Contributing to PoleStar-X

All contributions are welcome.

## How to Contribute

1. **Open an issue** describing the bug, feature request, or improvement.
2. **Wait for acknowledgment** from the maintainer before starting work.
3. **Fork the repo** and create a branch from `master`.
4. **Submit a pull request** referencing the issue.

All changes are accepted upon opening an issue and creating a pull request, but are subject to the repository maintainer's jurisdiction. The maintainer may request changes, reject, or merge at their discretion.

## Before Submitting a PR

```bash
npm run build
npm test
```

Both must pass.

## Code Style

- TypeScript strict mode
- No unnecessary abstractions
- Keep changes focused to the stated issue

## Questions?

Open an issue or start a discussion on GitHub.
